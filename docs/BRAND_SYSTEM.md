# Swift Deal Solutions Brand System

## Core identity retained

- Deep navy foundation
- Muted metallic gold accent
- Ivory/paper editorial surfaces
- Georgia-style editorial serif for high-impact headings
- Neutral sans-serif for operational information
- Thin-rule geometry and architectural grid systems
- Controlled luxury rather than ornamental luxury

## Experience principle

The brand should communicate that the transaction is being organized, not merely advertised.

Interfaces therefore use:

- mandate consoles
- evidence/status lists
- structured data rows
- stage selectors
- quiet motion
- strong whitespace
- explicit qualifiers

## Avoid

- fake deal statistics
- generic crypto/AI gradients
- exaggerated "exclusive network" claims without evidence
- excessive gold
- stock-photo grids without transaction context
- presenting illustrative profiles as completed deals
